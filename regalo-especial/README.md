# Un Regalo Especial 💕

Una experiencia web interactiva y romántica creada con amor para una persona especial.

## 🌟 Características

- Animaciones suaves y transiciones elegantes
- Diseño completamente responsivo (móvil, tablet, laptop)
- Efectos visuales hermosos:
  - Nieve cayendo
  - Lluvia de corazones de colores
  - Tulipanes flotantes
  - Ornamentos navideños
- Carrusel de videos con múltiples memorias
- Secciones temáticas con mensajes personalizados

## 🚀 Tecnologías Utilizadas

- HTML5
- CSS3 (Animaciones y efectos visuales)
- JavaScript (Vanilla JS)
- Canvas API para efectos de partículas

## 📱 Compatibilidad

- ✅ Navegadores modernos (Chrome, Firefox, Safari, Edge)
- ✅ Dispositivos móviles
- ✅ Tablets
- ✅ Desktop

## 🎨 Secciones

1. **Intro**: Mensaje de bienvenida con efecto de escritura
2. **Tulipanes**: Declaración de amor con tulipanes animados
3. **Rosas**: Galería de rosas con pétalos cayendo
4. **Videos**: Carrusel de momentos especiales
5. **Anime**: Sección temática con personajes y frases románticas
6. **Familia**: Mensaje de admiración
7. **Final**: Cierre emotivo

## 💝 Creado con amor

Este proyecto fue diseñado y desarrollado con mucho cariño para crear una experiencia única e inolvidable.
